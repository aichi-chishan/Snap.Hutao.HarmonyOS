# 账号与数据移植对齐（2026-11-11）

对照 `Snap.Hutao.Remastered-latest` 的 `3b7475e`（2.0.2.0），以实际命令、模型和页面为依据。范围限国服；胡桃云账号和游戏内存读取不在移植范围。

## 登录与账号

- 登录状态移至 `LoginViewModel`。进入页面自动创建二维码，刷新、切换方式和关闭页面使旧请求失效；按 `-3501` 识别二维码过期，保留三秒轮询。短信倒计时在离页清理，重复提交合并为当前操作。后台扫码期间保持请求，回到登录页后才执行返回，不弹走覆盖在其上的其他页面。
- 短信发送与登录继续使用原有 RSA、DS 和 aigis 链。页面失效后不再弹出验证或重放请求。账号落库取消复用 `UserService` 的会话版本检查。
- 移除国际服登录入口。国服新登录要求 SToken、有效 Token 交换和国服绑定角色；失败时保留之前的账号。Windows 密码和第三方登录仅属于国际服，本次不新增这些入口。
- Cookie 可逐账号复制完整 `key=value` 字段并重新导入。账号顺序可调整，备份恢复时随账号 ID 重映射。刷新凭据按实际交换结果报告成功，角色请求失败不会伪装成缓存同步成功。删除当前账号后选择排序中其余有效国服账号；删除账号同时清理其角色、便笺和签到缓存，保留独立 UID 档案。已接入官方旅行工具页面入口。
- 相同非空 MID 重新登录时保留完全未提供的完整凭据组，显式不完整的字段必须重新交换。启动恢复选中账号和重新登录时按 24 小时更新 CookieToken；时间戳仅在成功保存后写入本机，离线恢复可继续使用已有完整凭据。切换已存账号和备份后的本地会话加载仍不发批量初始化请求。
- `refreshCookieTokenForced(user, isActive?)` 支持后台续签的可选异步存活检查；任务失效中断网络后续步骤及凭据发布，非选中账号不会改变当前会话。
- 绑定角色可显示头像并手动刷新。直接读取公开 Enka 资料，按 `ProfilePicture.json` 匹配角色/服装图标，UID 缓存有效期 15 天；不使用胡桃云代理、不发送 Cookie/DS。失去页面或角色归属后不应用迟到结果。

## 日历与旅行者札记

- 日历采用当前养成项目的时区；没有项目时使用全局日历时区。设置保存在 `app.calendar_server_time_zone_offset`，当前项目按 Windows 的已有项目回退规则选择。首页可切换日期，活动、生日、材料和首页标记按同一时区计算，跨午夜会更新。应用语言改变时重读生日和材料名称，保留所选日期。
- 未保存周起始日时，按应用语言取默认值；跟随系统时保留完整语言和地区。显式保存的 0–6 优先。设置页统一接口为 `CalendarWeekService.firstDayOfWeek()` / `setFirstDayOfWeek(day)`。
- 补齐材料轮换系列、养成消费者高亮和每周起始日。上游材料表中 `114089` 与下一系列重叠，按游戏元数据修正为该系列最高阶 `114088`。
- 旅行者札记保留接口的最新月份语义（`month=0`）、月份选项、原石/摩拉环比与来源统计；缺失日数据不再显示成真实的零。账号、角色或月份改变后丢弃旧响应；同月刷新失败可以保留原统计并标明未刷新。
- 活动日历与札记只发国服请求，并在登录态续签、1034 验证和重放后检查请求归属。`getActionTicket` 增加可选 `actionType`，默认仍为 `game_role`，供官方旅行工具页面复用。

## 养成、库存、离线背包与备份

- 养成项目创建可选择时区；整项目同步保留用户目标等级，按角色技能 ID 匹配实际进度。完整计算器库存同步带 UID/服务器，并采用上游可计算角色和武器目录。
- `CultivationDraftViewModel.characterAndWeapon(uid, character)` 将角色与当前武器放进同一个编辑器；`batchCharacters(uid, characters)` 提供角色等级、A/E/Q 和武器等级的共同目标。各角色保留真实当前进度，低星武器遵守上限，缺失完整进度的角色列入跳过结果。保留/覆盖/另存为新条目在同一事务保存，现有单目标接口与 v1 草稿格式不变。
- 库存支持完整 492 种培养材料的检索与数量编辑、清空确认、文件导入及背包档案同步。项目删除、清空和导入保持事务一致；切换项目后的旧请求不再写入当前项目。
- 材料缺口与树脂统计复用同一轮换和合成规则，并按 Windows 计算富余经验书与低阶材料折算量。背包支持同类条件取并集、不同类条件取交集及多列排序；标准 UIIF 未提供的锁定、标记、装备和定向词条字段保留未知。档案版本单调增加，同毫秒修改也会使旧导入预览失效。
- 背包和库存按 ID 应用本地化名称，保留原始物品、数量、分类、评分及待确认导入。养成页可跳转到角色资料、武器资料和我的角色，图鉴保存目标默认沿用当前项目。
- 背包数量修改、分类和删除在事务内核对档案、实例 ID 与原始条目，拒绝修改导入替换后复用同一实例 ID 的其他物品；语言刷新也遵守同一详情归属。
- 背包定向词条显示现有属性名称，装备角色显示本地化名称及头像；未知 ID 保持可见，显示投影不修改 UIIF 原始字节。属性名称目前复用现有中文表。
- 数据库 v8→v9 仅为养成项目增加 `server_timezone_offset`，旧项目默认 UTC+8。旧版与新版本备份均保留对应项目数据；全局时区及每周起始日可往返。旧格式未包含的表不会预读后删除重插，直接保留其现状和相关偏好。还原后通知便笺和成就卡刷新。
- 备份提交及恢复日志收尾后，重新发布材质、减少动效、语言、背景和首页/日历状态；回滚不发布暂存偏好。`restoredPreferencesVersion` 供常驻页面应用主题/窗口、设置页刷新控件状态，消费者由主对话维护。
- 备份白名单精确补入树脂世界等级、图鉴网格、背景播放选项、AI 来源枚举和旧版角色评分选择；端点、密钥、设备路径与缓存仍不导出。旧格式恢复保留它无法表达的本地设置。
- 建表或迁移失败时等待关闭新建的 RdbStore，再抛出原始错误；并发初始化仍共享一次尝试，失败后可重试，不删除数据库。
