## 可复现测试

```bash
TYPESCRIPT_PATH=<TypeScript模块路径> node tests/ui-platform-contracts.cjs
```

该测试将**实际生产 `.ets` 服务/VM**以TypeScript转译执行，仅替换鸿蒙系统 I/O、网络与数据库依赖。覆盖日期、启动路由、元数据枚举、官方视频契约、切号异步隔离。它不替代 ArkTS 编译、HAP安装或UI交互测试。

## 明确剩余的可移植差距

- 角色资料“体型/所属”结构化筛选与角色皮肤Costumes：当前精简元数据没有完整对应字段，需要提取上游原始元数据并接线；不能将跨角色Swiper冒充皮肤选择。
- 角色云搭配/攻略信息还需和云服务模块核对；现有攻略按钮是米游社搜索与B站百科外链。
- 全应用语言包与Windows全部外观/窗口细项未逐项等价；当前主要为中文UI。支持的窗口操作应按HarmonyOS能力实现，Win32托盘/全局热键/任意进程控制无直接等价。
- 最新Windows背景视频支持目录递归随机；本轮使用文件选择器多选并导入私有目录，随机播放语义具备，目录自动发现新增文件语义仍不同。
- 远端壁纸前一天缓存回退、视频下载离线缓存、媒体管理/清理界面尚未实现；本轮视频官方源在线播放，本地视频可离线。
- 角色全部导出/技能加成等由数据agent实施，此记录不替其声明完成。

## 真实平台阻塞

- 没有厂商已确认的原神 HarmonyOS Bundle/公开 Ability/URI，故默认不填写虚构目标。用户可以填写实际已知入口，待厂商资料或设备确认后才可添加内置预设。
- 无可用API24/26设备、模拟器与签名，无法声称安装运行、全屏视频解码、桌面交互和系统拉起已实测。
- 普通HAP无法读取其他应用私有数据、控制其进程、改Windows注册表、执行exe或覆盖游戏安装资源；这些属于非注入平台差异，须在总功能矩阵单列。
