## 三、分批实施规划

每批验收：`hvigorw assembleHap` BUILD SUCCESSFUL / `devecocli check lint` Errors=0 / 主机回归 39+ 套件全绿 / API26 模拟器装机手测（模拟器可用时）。

- **R1 数据正确性与可达性（P0/P1 后端）**：B2 未登录本地祈愿视图 ✅ → B1 武器突破状态链 ✅（复核已核销，无需改动）→ B3 颂愿子池元数据 ✅（BeyondItem.json rawfile+热更管线、颂愿页专属物品图标 CDN、颂愿模式仅总览）→ B5 入口语义核验 ✅（已核销）。
- **R2 交互一致性（P1 前端）**：U1 统一命令栏 ✅（九页自绘标题行迁入 PageHeader 动作槽；图鉴三页因主从返回键保留自绘，形态一致）→ U3 状态呈现 ✅（便笺相对时间+估算标注+过期可区分；ErrorHint/EmptyState 体系沿用）→ U4 祈愿闭环 ✅（刷新结果摘要卡：来源/目标/新增/重复/失败分列+失败池单项重试）→ U2 键盘焦点 ✅（表单 Enter 提交与按键类型；Esc 关闭弹层属系统行为，自定义半窗暂不加全局键监听）。
- **R3 完善与精修（P2）**：B4 评分预设 → B6 UIGF 选择性互通 → B7 后台多 UID 与可观测 → B8 媒体管理 → B9 诊断 → B10/U10 外链类 → U5–U9 视觉精修批。
- **R4 独立大项（按需启动，需用户逐项确认）**：B11 i18n（先英文）→ B12 折叠屏专项 → B13 AI 通用工作区 → B14 云批次（推翻口径后）。

## 四、明确不做（维持口径）

- **注入域**：背包内存读取（本地离线背包/UIIF 保留）、游戏内悬浮、插件宿主（F30）、脚本控制台（F31）、注册表切号、启动游戏进程链、游戏安装/更新/预下载/校验（F28/F29）。
- **Windows 平台专属**：托盘/关闭行为（F32，鸿蒙为任务卡片语义）、全局热键（F27，鸿蒙无应用级全局键；应用内快捷键并入 U2）、MS Store 分发、ReadyToRun、帧率解锁、显示器识别、Island 外置覆盖窗。
- **胡桃云在线服务**（B14 单列）：通行证/云备份/云统计/战绩云上传/云攻略/云壁纸 API——按 2026-10-24 口径不实现，入口占位页保留，勿在占位页补实现。

## 五、口径冲突说明

本规划以 2026-10-24 确立的口径（仅国服、云不实现、注入不实现）为基准；若后续要求恢复云功能或海外支持，按 R4 独立批次立项，先行协议审计与凭据安全设计，不直接沿用旧实现结论。
