## 复测步骤

使用同一设备、界面布局、材质、语言和本地档案。记录应用版本、HAP 的 SHA-256、工具版本与样本时间。将首次进入和预热重入作为两组场景。

1. **冷启动**。在应用空闲时结束指定包的进程，以 `aa start -W` 启动该包。记录 `LaunchState: Cold` 对应的 `TotalTime`。每次等待首页数据加载完成后再开始下一轮。[华为 AA 使用说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/aa-tool/)
2. **祈愿数据发布**。先访问一次祈愿页，再回主页。每次在相同位置点击导航，点击前取设备 `date +%s%N`。从同一 PID 的 `hilog -v epoch` 中提取标记之后首个 `syncPoolCards` 且 `cards>0` 的时间，与设备端标记做差。[HiLog 文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hilog/)
3. **可访问节点**。用主机单调时钟记录点击命令开始和 `devecocli ui find` 找到“总览”的时刻，两者之差涵盖命令与节点查询。需要物理呈现耗时时，用 DevEco Profiler 关联应用渲染事务与显示呈现事件。[华为启动分析](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ide-profiler-launch-case/)
4. 分别保存每组有效样本，偶数个样本的中位数取中间两项平均，p90 使用 nearest-rank。记录未找到对应事件的次数及原因。

PowerShell 示例，先将 `$Target` 设为自己的目标设备，`hdc` 使用 SDK 中的工具：

```powershell
$Bundle = 'com.example.snaphutaoharmonyos'
hdc -t $Target shell aa force-stop $Bundle
hdc -t $Target shell aa start -W -a EntryAbility -b $Bundle -m entry
$AppProcess = (hdc -t $Target shell pidof $Bundle).Trim()
hdc -t $Target shell hilog -x -P $AppProcess -T SnapHutao -v epoch -v usec |
  Select-String 'syncPoolCards'
```
